# What is QSim?

Q-Sim is an RPG engine for games like Squaresoft's Final Fantasy 7, Final Fantasy IX or Xenogears. It is designed to be cross-platfrom and run on modern operating systems such as Win32 and Linux.

Q-Sim is a fork of the [Q-Gears](https://github.com/q-gears/q-gears) engine, all credit for the original engine goes to the Q-Gears authors (see AUTHORS.md).

Q-Sim renders through [OGRE](https://www.ogre3d.org/) 14 and its **Vulkan** render system. Materials written in the old fixed function style get their shaders generated by OGRE's RT Shader System.

### How do I build QSim?

Requirements:

* CMake 3.16 or newer and a C++17 compiler (GCC 9+, Clang 10+, Visual Studio 2019+)
* OGRE 14 built with the Vulkan render system, the GLSLang plugin, Bites, Overlay and RTShaderSystem
* Vulkan loader and headers, glslang
* OIS, Boost (program_options, filesystem, unit_test_framework), zlib
* Qt 6 (or Qt 5) for the launcher (optional: `-DQSim_BUILD_LAUNCHER=OFF`)

#### Ubuntu Linux 24.04

**Install required packages:**
```
sudo apt-get update
sudo apt-get install git build-essential cmake ninja-build \
    libvulkan-dev glslang-dev glslang-tools mesa-vulkan-drivers \
    libois-dev libboost-all-dev zlib1g-dev qt6-base-dev \
    libopenal-dev libvorbis-dev libx11-dev libxrandr-dev libxaw7-dev libsdl2-dev libfreetype-dev
```

**Build OGRE 14 with Vulkan** (distributions only ship OGRE 1.12, which has no Vulkan support):
```
git clone --depth 1 -b v14.6.2 https://github.com/OGRECave/ogre.git ogre
cmake -S ogre -B ogre/build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/opt/ogre14 \
    -DOGRE_BUILD_RENDERSYSTEM_VULKAN=ON -DOGRE_BUILD_COMPONENT_OVERLAY_IMGUI=OFF \
    -DOGRE_BUILD_SAMPLES=OFF -DOGRE_BUILD_TESTS=OFF
cmake --build ogre/build
sudo cmake --install ogre/build
```

**Sync down the QSim source code:**
```
git clone --recursive https://github.com/rabbitgamerworks-bit/q-sim.git
cd q-sim
```

**Build the code:**
```
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=/opt/ogre14
cmake --build build
ctest --test-dir build
```

`build/bin_release/plugins.cfg` is generated for the OGRE installation q-sim was configured with. To run the game from the `output` directory:
```
cd output
../build/bin_release/q-sim --plugins-file ../build/bin_release/plugins.cfg --resources-file resources.cfg_linux
```

Q-Sim uses Vulkan by default. Pass `--config-dialog` to pick another render system or resolution. If OGRE's media can not be found, point `QSIM_OGRE_MEDIA_DIR` at the `Media` directory of the OGRE installation.

#### Building DEB package for Linux

To do this use "cpack -C Debug" or "cpack -C Release" after running the build.

#### Windows

Install Visual Studio 2022, CMake, Git, the [Vulkan SDK](https://vulkan.lunarg.com/), Qt 6 and Boost (for example through [vcpkg](https://vcpkg.io): `vcpkg install boost-program-options boost-filesystem boost-test ois zlib`).

Build OGRE 14 with `-DOGRE_BUILD_RENDERSYSTEM_VULKAN=ON` (as above) and install it, then configure q-sim pointing CMake at it:
```
git clone --recursive https://github.com/rabbitgamerworks-bit/q-sim.git
cd q-sim
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/ogre14;C:/Qt/6.x/msvc2022_64" -DCMAKE_TOOLCHAIN_FILE=C:/vcpkg/scripts/buildsystems/vcpkg.cmake
cmake --build build --config Release
```

To build the installer build the "PACKAGE" project, or run "cpack -C Release" (WIX toolkit required).
